About PackCheck

Smart India Hackathon Project — Packaged Commodity Compliance & Consumer Awareness System

Problem Statement

Consumers often lack the tools to verify whether packaged products comply with mandatory labelling regulations. Missing MRP, absent manufacturer details, or undeclared expiry dates go unnoticed — putting consumers at risk.

Our Solution

PackCheck uses computer vision (OpenCV + Tesseract OCR) to extract product label information from images, then verifies the data against configurable compliance rules. The result is a transparent compliance score with clear pass/fail indicators and actionable recommendations.

Technology Stack

  • ⚙️ Backend: Python, Flask, REST API
  • 🎨 Frontend: HTML5, CSS3, Vanilla JavaScript
  • 🗄️ Database: MySQL
  • 👁️ Vision: OpenCV, Tesseract OCR
  • 📱 Scanning: pyzbar (barcode/QR)

This is a demonstration project built for the Smart India Hackathon. It is not an official regulatory or certification tool.
